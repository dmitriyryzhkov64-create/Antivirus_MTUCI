# TrayApp

Графическое приложение Windows на C++ Win32 API.

## Возможности

- Иконка в области уведомлений панели задач.
- Левый клик по иконке открывает главное окно.
- Правый клик показывает контекстное меню.
- Контекстное меню содержит пункты "Открыть" и "Выход".
- При закрытии главного окна приложение продолжает работать в фоне.
- Меню главного окна: "Файл" -> "Выход".
- Поддержка запуска без показа главного окна: `TrayApp.exe --hidden`.
- Защита от повторного запуска через именованный mutex.
- Восстановление иконки после пересоздания панели задач.
- Сборка через CMake.
- CI-сборка через GitHub Actions.

## Локальная сборка
